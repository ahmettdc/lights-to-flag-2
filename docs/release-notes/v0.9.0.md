# Lights to Flag 2 — v0.9.0 (pre-release)

The first packaged build of the ground-up **C# / .NET 9 + Avalonia** rebuild. You play a
**Team Principal** in a fictional motorsport world: run the budget, the R&D programme, the
staff and the driver line-up, and call both cars' strategy on the pit wall — under board and
media pressure, across an endless run of seasons.

This is a **pre-1.0** build: the full career and race loop is playable end to end, but it is not
yet a finished, tutorialised product (see *Known limitations*).

---

## What's in v0.9

### Career & season loop
- A living, **endless career**: a Football-Manager-style **Continue** advances the calendar to the
  next event, races it, updates the championship, and rolls into the next season automatically.
- **New Team Principal career** with an interactive **board negotiation** at signing.
- **Save / load** with multiple slots; a dated **inbox** feed that can pause the career when a
  decision is required.
- **Quick Race** for a one-off race outside a career.

### Race weekend & live racing
- A **live timing tower** that replays the round the engine just ran — running order, gaps,
  tyres, pit counts, an event feed, and the final classification, with play / pause / speed.
- A **schematic track map** with moving car markers, **sector colours** and a **team-radio** feed.
- **Qualifying** tab (the grid the round started from).
- **Pre-race strategy**: pick each of your drivers' starting tyres.
- **Race Live** — drive the upcoming round a lap at a time and issue real pit-wall orders
  (**Box / Push / Extend stint / Manage tyres**); the result is fully reproducible on reload.

### Management
- Five management screens: **Finance** (with a bank & credit line you can draw on), **R&D &
  Facilities**, **Cars & Power Unit**, **Staff** (hire / release), **Board & Sponsors**.
- A live economy each season boundary: income, budget-cap enforcement, loan settlement and
  graduated enforcement, and a board review.
- **In-season R&D** — the car develops round by round toward a concept you steer, under an FIA
  development-freeze regime.

### The wider world
- **Driver development** — potential, ageing, growth and decline, retirement, fictional rookies,
  and a **transfer window** that reshuffles the grid between seasons.
- **Regulation changes** that set back the teams least prepared for them.

### Statistics & records (new in the run up to v0.9 — M24)
- A dedicated **RECORDS** screen: **career profiles** (ranked, with each driver's full record),
  **this-season** leaders + a teammate **head-to-head** + a hand-drawn **points-progression chart**,
  **all-time** record boards, and a **Hall of Fame** (year-by-year champions + per-circuit lap records).
- The archive is **persisted** across the whole career, so multi-season trends and track records
  survive save / load.

### Under the hood
- A **deterministic** race engine: the same carset and seed reproduce the same season, bit for
  bit, on Windows, macOS and Linux (guarded by a golden-digest test).
- **Byte-identical saves** (idempotent round-trips).
- **784 automated tests** green across seven test projects.

## Install & run (Windows)

1. Download `LightsToFlag2-v0.9.0-win-x64.zip` from the release assets below.
2. Extract it anywhere. It is **self-contained** — you do **not** need .NET installed.
3. Run **`LightsToFlag2\LTF.App.exe`**.

Windows SmartScreen may warn about an unknown publisher (the build is not code-signed yet) —
choose *More info → Run anyway*.

**Saves** live in `%AppData%\LightsToFlag2\` (settings and save slots), so they survive moving or
deleting the app folder.

---

## Known limitations

- **Windows only** for now. macOS is a planned ship target but needs code signing before it can
  be distributed; it is not in this release.
- **No installer / auto-update** yet (that's a later milestone). This is a plain extract-and-run zip.
- **Not code-signed** — hence the SmartScreen prompt above.
- **No in-game tutorial** yet (the guided first weekend is the next milestone, M25).
