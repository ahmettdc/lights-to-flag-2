# ADR-0022 — Dinamik Dünya Sistemi (yaşayan evren)

- **Durum:** Kabul edildi
- **Tarih:** 2026-08-05

## Karar
Oyuncu hiçbir şey yapmasa bile dünya kendi kendine yaşar. **7 ekosistem** + haber/söylenti motoru +
tarih veritabanı + hall of fame. Hedef: uzun kariyerde grid/takım/şampiyon/kural/sponsor/üretici
oyuncudan bağımsız değişmiş olur; her kariyer benzersiz.

## Yedi ekosistem
Takım (sahiplik türleri, satın alma/devir, iflas, yeni giriş) · Sürücü (yaşlanma / CA-PA / gizli
özellik / akademi / yetenek patlaması / çöküş / emeklilik — ADR-0015/0017) · Personel (kaçırma /
ağaç / terfi / ayrılık) · Üretici (giriş/çıkış / motor savaşı / fabrika takımı) · Sponsor (yaşam
döngüsü / kriz) · Regülasyon (FIA oyları + 4-6 yıllık döngü + beklenmeyen değişiklik — ADR-0010/
0018) · Global olay (ekonomik kriz / teknoloji / jeopolitik / pandemi-benzeri, soyut).

## Mevcut kararların derinleşmesi
M18 (sezon devri) ana yüzey; ADR-0015 (sürücü yaşam döngüsü), ADR-0017 (havuz/akademi), ADR-0010/
0018 (regülasyon döngüsü — **26a çoklu-çağ motoru bu mekanizmanın altyapısıdır**), M13 (finans),
M14 (personel).

## Determinizm & hassasiyet (kritik)
Tüm evrim **tohumlu** (aynı tohum+kararlar → aynı dünya; ADR-0002). İçerik kurgusal/isimsiz
(ADR-0003); gerçek marka/isim yalnız kullanıcı modu (ADR-0007/0023). Global olaylar soyut; gerçek
trajedi canlandırması yok (ADR-0012).

## Milestone dağılımı
**M18 ana yüzey**, M11 (dünya durumu + tarih/haber), M13/M14 (finans/personel ekosistemi), M24
(tarih/hall of fame), Rev 15/21 (haber → bildirim/medya). Alt-sistem K. M2 opsiyonel başlangıç
dünya durumu.

## Sonuç
Oyunun en büyük gücü tek yarış değil; oyuncudan bağımsız yaşayan bir motorsporları evreni olur.
